## Python

**Python** — высокоуровневый интерпретируемый язык программирования общего назначения. В контексте DevOps используется для автоматизации, написания скриптов, работы с API и инфраструктурой.

### Ключевые концепции

| Концепция | Описание |
|---|---|
| Интерпретируемость | Код выполняется построчно интерпретатором, без этапа компиляции |
| Динамическая типизация | Тип переменной определяется во время выполнения |
| PIP | Пакетный менеджер для установки библиотек (`pip install requests`) |
| venv | Виртуальное окружение для изоляции зависимостей проекта |
| Shebang | Строка `#!/usr/bin/env python3` в начале скрипта для прямого запуска |

### Применение в DevOps

```python
# Пример: скрипт проверки здоровья сервиса
import requests, sys

response = requests.get("http://localhost:8080/health")
if response.status_code != 200:
    print(f"Service unhealthy: {response.status_code}")
    sys.exit(1)
print("Service OK")
```

- **Автоматизация**: скрипты деплоя, парсинг логов, работа с облачными API (boto3, google-cloud)
- **Ansible**: написан на Python, модули расширения пишутся на Python
- **CLI-утилиты**: Click, Typer — фреймворки для создания инструментов командной строки

## Process Monitoring (Мониторинг процессов)

Мониторинг процессов — отслеживание состояния запущенных процессов в ОС: потребление CPU, памяти, статус, дочерние процессы.

### Основные утилиты

| Команда | Описание | Пример |
|---|---|---|
| `ps` | Снимок текущих процессов | `ps aux` — все процессы с деталями |
| `top` | Интерактивный мониторинг в реальном времени | `top -u nginx` — процессы пользователя nginx |
| `htop` | Улучшенный top с цветным интерфейсом | `htop -t` — древовидное отображение |
| `kill` | Отправка сигнала процессу | `kill -9 1234` — принудительное завершение |
| `pgrep/pkill` | Поиск/завершение по имени | `pkill -f "python app.py"` |
| `systemctl` | Управление systemd-сервисами | `systemctl status nginx` |
| `journalctl` | Просмотр логов systemd | `journalctl -u nginx -f` — логи в реальном времени |

### Сигналы процессов

```
SIGTERM (15) — корректное завершение (по умолчанию)
SIGKILL (9)  — принудительное завершение (нельзя перехватить)
SIGHUP  (1)  — перезагрузка конфигурации
SIGUSR1 (10) — пользовательский сигнал
```

## Performance Monitoring (Мониторинг производительности)

Отслеживание производительности системы: CPU, RAM, диск, сеть, I/O.

### Основные инструменты

| Инструмент | Область | Пример |
|---|---|---|
| `vmstat` | CPU, память, I/O | `vmstat 1 5` — замеры каждую секунду, 5 раз |
| `iostat` | Дисковый I/O | `iostat -x 1` — расширенная статистика |
| `free` | Оперативная память | `free -h` — в человекочитаемом формате |
| `df` | Дисковое пространство | `df -h` — занятость файловых систем |
| `du` | Размер директорий | `du -sh /var/log/*` — размер каждого лога |
| `sar` | Историческая статистика | `sar -u 1 10` — загрузка CPU |
| `nmon` | Комплексный мониторинг | Интерактивный режим |
| `dmesg` | Сообщения ядра | `dmesg -T` — с метками времени |

## Networking Tools (Сетевые инструменты)

| Команда | Назначение | Пример |
|---|---|---|
| `ip` | Управление интерфейсами и маршрутами | `ip addr show`, `ip route` |
| `ss` | Информация о сокетах (замена netstat) | `ss -tlnp` — слушающие TCP-порты |
| `ping` | Проверка доступности хоста | `ping -c 4 google.com` |
| `traceroute` | Маршрут до хоста | `traceroute 8.8.8.8` |
| `dig` | DNS-запросы | `dig example.com A` |
| `nslookup` | DNS-разрешение | `nslookup example.com` |
| `curl` | HTTP-запросы | `curl -I https://example.com` |
| `wget` | Скачивание файлов | `wget https://example.com/file.tar.gz` |
| `nmap` | Сканирование портов | `nmap -sV 192.168.1.1` |
| `tcpdump` | Захват сетевого трафика | `tcpdump -i eth0 port 80` |
| `iptables/nftables` | Файрвол и NAT | `iptables -L -n` — правила |

## Text Manipulation (Обработка текста)

| Команда | Назначение | Пример |
|---|---|---|
| `grep` | Поиск по паттерну | `grep -r "error" /var/log/` |
| `sed` | Потоковое редактирование | `sed -i 's/old/new/g' file.txt` |
| `awk` | Обработка колоночных данных | `awk '{print $1, $3}' access.log` |
| `cut` | Извлечение полей | `cut -d: -f1 /etc/passwd` |
| `sort` | Сортировка строк | `sort -t: -k3 -n /etc/passwd` |
| `uniq` | Удаление дубликатов | `sort file | uniq -c` — с подсчётом |
| `wc` | Подсчёт строк/слов/символов | `wc -l access.log` |
| `tr` | Замена/удаление символов | `echo "HELLO" | tr A-Z a-z` |
| `jq` | Обработка JSON | `cat data.json | jq '.items[].name'` |
| `yq` | Обработка YAML | `yq '.spec.replicas' deploy.yaml` |

### Пример конвейера

```bash
# Топ-10 IP-адресов по количеству запросов в access.log
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10
```

## Vim и Nano

### Vim

Модальный текстовый редактор с тремя основными режимами:

| Режим | Вход | Назначение |
|---|---|---|
| Normal | `Esc` | Навигация и команды |
| Insert | `i`, `a`, `o` | Ввод текста |
| Command | `:` | Команды (сохранение, выход, поиск) |

**Основные команды:**
- `:w` — сохранить, `:q` — выйти, `:wq` — сохранить и выйти, `:q!` — выйти без сохранения
- `dd` — удалить строку, `yy` — копировать, `p` — вставить
- `/pattern` — поиск, `:%s/old/new/g` — замена во всём файле

### Nano

Простой текстовый редактор с подсказками команд внизу экрана:
- `Ctrl+O` — сохранить, `Ctrl+X` — выйти
- `Ctrl+W` — поиск, `Ctrl+K` — вырезать строку, `Ctrl+U` — вставить

## FreeBSD

**FreeBSD** — свободная Unix-подобная ОС, известная стабильностью и производительностью.

| Особенность | Описание |
|---|---|
| Пакетный менеджер | `pkg install nginx` |
| Ports | Сборка ПО из исходников: `/usr/ports/` |
| Файловая система | ZFS — по умолчанию, с снапшотами и RAID |
| Файрвол | `pf` (Packet Filter) — мощный и гибкий |
| Jails | Лёгкая контейнеризация (предшественник Docker) |
| Сеть | Высокопроизводительный сетевой стек |

**Применение:** серверы (Netflix, WhatsApp), сетевые устройства, встраиваемые системы.

## Ubuntu

**Ubuntu** — популярнейший дистрибутив Linux на базе Debian.

| Особенность | Описание |
|---|---|
| Пакетный менеджер | `apt install nginx` (или `apt-get`) |
| Snap | Универсальные пакеты: `snap install kubectl --classic` |
| Systemd | Система инициализации и управления сервисами |
| UFW | Упрощённый файрвол: `ufw allow 22/tcp` |
| LTS-релизы | Долгосрочная поддержка 5 лет (22.04, 24.04) |
| Cloud-init | Автоматическая настройка при запуске в облаке |

**Применение:** серверы, облачные инстансы, WSL, контейнеры, рабочие станции разработчиков.
