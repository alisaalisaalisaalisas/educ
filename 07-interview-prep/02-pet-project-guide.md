## 🚀 Быстрый старт стенда

Мы подготовим шаблон `docker-compose.yml` и конфигурационные файлы, чтобы весь стенд поднимался одной командой:

```bash
# Клонирование / запуск
docker compose up -d
```

### Доступные сервисы после запуска:
* **Grafana:** `http://localhost:3000` (логин/пароль: `admin` / `admin`)
* **Prometheus:** `http://localhost:9090`
* **Alertmanager:** `http://localhost:9093`
* **Node Exporter:** `http://localhost:9100/metrics`
* **Демо веб-приложение:** `http://localhost:80`

## 🧪 Сценарии симуляции аварий (Chaos Engineering для тренировки)

1. **Симуляция утечки памяти (Memory Leak):** запустить процесс, аллоцирующий память, и проверить срабатывание алерта.
2. **Симуляция 502 Bad Gateway:** остановить бэкенд и проверить, как Nginx фиксирует ошибку, а Grafana строит график сбоя.
3. **Симуляция переполнения диска:** создать временный файл большого объема через `fallocate` и наблюдать за алертом в Telegram.
