# 🚨 Модуль 6.1: Жизненный цикл инцидента и эскалация

Работа дежурного инженера заключается не в том, чтобы «паниковать при красном алерте», а в том, чтобы следовать четкому протоколу управления инцидентами.

---

## 1. Фазы жизненного цикла инцидента

```
[1. Обнаружение] ➔ [2. Триаж (Triage)] ➔ [3. Локализация / Workaround] ➔ [4. Эскалация] ➔ [5. Восстановление] ➔ [6. Post-Mortem]
```

1. **Обнаружение (Detection):** Сработал алерт в Telegram/PagerDuty или поступил звонок из поддержки/L1.
2. **Триаж и приоритизация (Triage):**
   * Оценка масштаба влияния (Impact): *Сколько пользователей затронуто? Работает ли оплата?*
   * Определение критичности (Severity): **P1/Sev1 (Блокирующий)**, **P2 (Высокий)**, **P3 (Средний)**.
3. **Локализация (Mitigation / Workaround):**
   * Задача дежурного — **как можно быстрее вернуть сервис к жизни** (откатить релиз, перезапустить упавший pod, включить режим заглушки), а глубокое расследование бага отложить на потом.
4. **Эскалация (Escalation):**
   * Если по Runbook проблему решить за 10–15 минут не удается, немедленно привлекаются профильные инженеры (On-Call DevOps, DBA, Lead Backend).
5. **Коммуникация:**
   * Публикация статуса в аварийном канале (Status Page / Incident Chat): «Мы в курсе проблемы X, работаем над устранением. ETA: 20 минут».
6. **Post-Mortem (Ретроспектива без обвинений - Blameless):**
   * Анализ причин: *Почему упало? Как обнаружить раньше? Что сделать, чтобы это никогда не повторилось?*

---

## 2. Матрица эскалации (Escalation Matrix)

| Уровень | Кто отвечает | Когда привлекается |
| :--- | :--- | :--- |
| **L1 (Дежурный мониторинга)** | Ты | Первичное обнаружение, проверка по Runbook, перезапуск по инструкции. |
| **L2 (Системный администратор / DevOps)** | On-Call Engineer | Проблемы с инфраструктурой, железом, сетью, сломанные пайплайны. |
| **L3 (Разработчики / Архитекторы)** | Dev Team Lead | Баги в коде, повреждение данных в БД, логические сбои бизнес-логики. |
| **Incident Commander** | Руководитель дежурной смены | Координирует общую коммуникацию при крупных авариях (P1). |
