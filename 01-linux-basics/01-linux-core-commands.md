# 🐧 Модуль 1.1: Основные команды Linux для инженера мониторинга

Терминал — главный инструмент инженера. Ниже собраны команды, которые используются каждый день при анализе состояния системы.

---

## 1. Навигация и работа с файлами

| Команда | Описание | Пример использования |
| :--- | :--- | :--- |
| `ls -la` | Список всех файлов с правами, владельцами и размерами | `ls -lah /var/log/` |
| `cd` | Переход в директорию | `cd /etc/nginx/` |
| `pwd` | Показать текущий путь | `pwd` |
| `cat` / `less` | Просмотр содержимого файла | `less /var/log/syslog` |
| `head` / `tail` | Первые/последние N строк файла | `tail -n 50 /var/log/nginx/access.log` |
| `tail -f` | Мониторинг файла логов в реальном времени | `tail -f /var/log/nginx/error.log` |
| `find` | Поиск файлов по имени, времени, размеру | `find /var/log -type f -name "*.log" -mtime +7` |

## 2. Фильтрация и анализ текста (Логи)

Главная связка дежурного инженера: `grep`, `awk`, `sort`, `uniq`, `wc`.

```bash
# 1. Поиск критических ошибок в логе (без учета регистра)
grep -i "error" /var/log/syslog

# 2. Рекурсивный поиск с номерами строк
grep -rn "502 Bad Gateway" /var/log/nginx/

# 3. Исключение лишних строк (инвертированный поиск)
grep -v "DEBUG" app.log

# 4. Подсчет количества определенных строк в логе
grep "POST /api/login" /var/log/nginx/access.log | wc -l

# 5. Топ-10 IP адресов с наибольшим количеством запросов
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -nr | head -n 10
```

### 🧩 Декодер самых частых флагов в Linux:

| Команда | Флаги | Расшифровка каждого флага |
| :--- | :--- | :--- |
| `ls -lah` | `-l -a -h` | `-l` (**l**ong) подробный список, `-a` (**a**ll) включая скрытые `.dotfiles`, `-h` (**h**uman-readable) размеры в КБ/МБ/ГБ. |
| `grep -rn` | `-r -n` | `-r` (**r**ecursive) искать во всех подпапках, `-n` (**n**umber) показывать номер строки в файле. |
| `grep -i` | `-i` | `-i` (**i**gnore-case) не обращать внимания на БОЛЬШИЕ и маленькие буквы. |
| `grep -v` | `-v` | `-v` (in**v**ert) показать всё, где НЕТ совпадения (исключить). |
| `tail -f` | `-f` | `-f` (**f**ollow) следить за файлом на лету при добавлении новых строк. |
| `tar -czvf` | `-c -z -v -f` | `-c` (**c**reate) создать архив, `-z` (g**z**ip) сжать, `-v` (**v**erbose) показывать файлы, `-f` (**f**ile) имя файла архива. |
| `ps aux` | `a u x` | `a` (все пользователи), `u` (показать пользователя и %CPU/%MEM), `x` (процессы без терминала/демоны). |
| `df -h` | `-h` | `-h` (**h**uman-readable) вывод в ГБ вместо килобайт. |
| `df -i` | `-i` | `-i` (**i**nodes) количество индексных дескрипторов (мелких файлов). |

## 3. Права доступа и владельцы

* Формат прав: `r` (чтение = 4), `w` (запись = 2), `x` (выполнение = 1).
* Пример: `chmod 755 script.sh` (`rwxr-xr-x`).

```bash
# Смена владельца и группы
chown -R www-data:www-data /var/www/html

# Изменение прав
chmod 644 /etc/nginx/nginx.conf
chmod +x /usr/local/bin/check_service.sh
```

## 4. Управление службами (systemd)

В подавляющем большинстве современных Linux систем управление сервисами идет через `systemctl` и `journalctl`.

```bash
# Статус сервиса (работает / упал / перезапускается)
systemctl status nginx

# Перезапуск / остановка / запуск
systemctl restart nginx
systemctl stop nginx
systemctl start nginx

# Включение автозапуска при загрузке системы
systemctl enable nginx
systemctl disable nginx

# Просмотр логов конкретного сервиса через journalctl
journalctl -u nginx -n 100 --no-pager
journalctl -u nginx -f                  # В реальном времени
journalctl -u nginx --since "1 hour ago" # За последний час
journalctl -p err..emerg                # Только ошибки и критические сбои
```
